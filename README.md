# flynode-byoc

Customer-submitted ("Bring Your Own Compose") deployment sources for FlyNode. Each subdirectory under `byoc/<deploymentId>/` holds one customer's raw `docker-compose.yaml`, committed by the API's BYOC endpoint — never edited by hand.

Kept separate from [flynode-templates](https://github.com/mhmehedi/flynode-templates), which holds our own curated, hand-verified templates. Content here is untrusted user input.
